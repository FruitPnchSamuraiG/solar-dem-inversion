# DEM Inversion — Deep Learning for Solar Physics

## Project Overview

Collaborative project with a PhD student (astrophysics domain) to improve **Differential Emission Measure (DEM) inversion** using deep learning. The goal is to produce faster, more accurate approximations of DEM curves compared to classical optimization solvers.

**Hriday's role**: Deep learning expertise — architecture, training, uncertainty modeling.
**PhD student's role**: Astrophysics domain, reference solver implementations, data.

## What is DEM?

The **Differential Emission Measure** is a function that describes how much solar coronal plasma exists at each temperature along a line of sight. It is a key diagnostic for the thermal structure of the Sun's corona.

- **Input**: Calibrated EUV image stack from SDO/AIA (6 channels: 94, 131, 171, 193, 211, 335 Å). Optionally also Hinode/XRT data for high-temperature constraints.
- **Output**: DEM profile (values per temperature bin, logT 5.5 to 8) + uncertainty estimates per bin.
- **Why deep learning**: Classical solvers are computationally expensive (optimization/MCMC per pixel). The NN runs orders of magnitude faster at full SDO/AIA resolution.

## Reference Solvers Being Emulated

The NNs are trained to emulate two classical inversion methods:

### 1. Basis Pursuit (BP) — Cheung et al. 2015
Sparse L1 solution:
```
argmin_{x≥0} 1^T x  s.t.  (o - tσ) ≤ Rx ≤ (o + tσ)
```
Finds sparsest DEM that reconstructs the observation within t standard deviations. Tolerances are relaxed iteratively (t=1.4 → 2.8 etc.).

### 2. Elastic Net (ENet) — Athiray & Winebarger 2024
L1 + L2 regularized reconstruction:
```
argmin_{x≥0} (1/2C)||o - Rx||² + αλ||x||₁ + (1/2)α(1-λ)||x||²₂
```
Trades data fidelity vs. regularization. Assumes smoothness across DEM bins. (Lasso is λ=1 special case, solved by LassoLars in scikit-learn.)

**R** is the temperature response matrix encoding how each AIA channel responds to plasma at each temperature.

## Four Trained Models

| Name | Solver | Inputs |
|------|--------|--------|
| NN on BP with AIA | Basis Pursuit | AIA only |
| NN on BP with AIA+XRT | Basis Pursuit | AIA + Hinode/XRT |
| NN on ENet with AIA | Elastic Net | AIA only |
| NN on ENet with AIA+XRT | Elastic Net | AIA + Hinode/XRT |

## Architecture (DeepEM Modernization)

Three key improvements over original DeepEM (Wright et al. 2019):

1. **Inputs**: Per-pixel EUV observations lifted to a high-dimensional space (inspired by neural radiance fields / NeRF) for finer-grained distinctions.
2. **Network body**: Wider and deeper than DeepEM; SiLU activations (differentiable everywhere, outperforms ReLU).
3. **Output / uncertainties**: Predicts both a single best estimate AND a distribution over outputs (binned probability distribution à la SuperSynthIA). Uncertainty is estimated by running the solver on perturbed inputs (simulated photon noise) — the NN learns to reproduce this distribution in a single forward pass.

## Training Setup

- 2-year SDO/AIA dataset, twice-daily cadence (~1460 samples)
- Trained per pixel at full AIA resolution (4096×4096, but inference is per-pixel NN)
- Labels generated by running reference BP/ENet solvers on the dataset

## Key Domain Vocabulary

| Term | Meaning |
|------|---------|
| AIA | Atmospheric Imaging Assembly (instrument on SDO satellite) |
| SDO | Solar Dynamics Observatory (NASA satellite) |
| XRT | X-Ray Telescope (on Hinode satellite) |
| EUV | Extreme Ultraviolet — the wavelength bands AIA observes |
| logT | Log₁₀ of temperature (K). DEM bins span logT 5.5–8 |
| JPDF | Joint Probability Distribution Function |
| PSF | Point Spread Function — instrument blurring; AIA has a well-characterized PSF |
| Deconvolution | Correcting for PSF blur using `aiapy.psf.deconvolve` |
| AR / HARP | Active Region / HMI Active Region Patch — regions of solar magnetic activity |
| Flare classes | X, M, C, B — X-ray flare intensity. X8.2 > X1.6 > M5 > C2.4 |
